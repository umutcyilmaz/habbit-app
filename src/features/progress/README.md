# Progress Feature

Owns Progress Overview, Insights, Weekly Review, and Next Week Focus.

Progress is awareness-based and should summarize patterns without comparative labels.

## Current Implementation

The Progress tab is implemented as a mock overview using `data/progressMockData.ts`.

It includes:

- Weekly summary metrics.
- Gentle observations.
- Helpful tool cards.
- Weekly review preview.
- Optional low-data mock state.

There is intentionally no persistence, stored-data calculation, advanced reporting, AI-generated insight, subscription behavior, or backend sync yet.
