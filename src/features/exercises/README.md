# Exercises Feature

Owns the basic exercises library, including 90-Second Pause, breathing reset, arousal awareness, and content support.

Exercise content should be practical, discreet, and not therapy-heavy.

## Current Implementation

The Exercises tab is implemented as a mock support toolbox:

- Recommended exercise card.
- Category sections.
- Available and coming-next exercise cards.
- 90-Second Pause routes to `/pause`.
- Quick Check-In routes to the Log tab.

There is intentionally no persistence, audio, video, advanced coaching, progress tracking, or paywall behavior yet.
