# Protect Feature

Owns Protection Center, Sensitive Window Setup, and Protected Window Delay.

Protection means optional gentle support. It is not a hard stop and should remain editable and reversible.

## Current Implementation

The Protect tab is implemented as a local skeleton using mock context from the Progress sensitive-window idea:

- Suggested evening window.
- Setup state.
- Support level selection.
- Active support state.
- Paused and off states.
- Protected window preview.

There is intentionally no persistence, notification scheduling, content detection, device-level filtering, background tasks, analytics, or backend sync yet.
