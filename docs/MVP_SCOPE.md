# MVP Scope

## Must Have

- Onboarding quick path
- Safety note
- Privacy / trust screen
- Today dashboard
- Quick Check-In
- Pause Now
- 90-Second Pause
- Daily Log
- Basic Exercises
- Basic Progress
- Basic Protection
- Profile & Privacy
- Data deletion basics
- Notification privacy basics
- Empty states
- Error states

## Should Have

- Content Support
- Arousal Awareness Practice
- Weekly Review
- Next Week Focus
- Sensitive Window suggestions
- Data export
- App Lock
- Reminders

## Later / Premium

- Long-term trends
- Advanced insights
- Custom routines
- Multiple profiles
- Full coaching library
- Advanced reports
- Deep adaptive plans

## Intentionally Excluded From MVP

- Backend sync.
- Authentication.
- AI API calls.
- Payment integration.
- Social features.
- Community content.
- Medical diagnosis, treatment, or clinical recommendations.
- Hard blocking of adult content.
- Device-level surveillance.
- Sensitive content analytics.
- Performance scores.
- Abstinence streak mechanics.
- Multiple profiles.
- Advanced reports.

## MVP Success Criteria

The MVP is successful if an adult user like Mert can:

- Understand Bloom's purpose and boundaries in under two minutes.
- Finish onboarding without sharing more than needed.
- Use Today as a calm daily home base.
- Pause before an automatic loop.
- Log a moment without feeling judged.
- See basic awareness patterns over time.
- Configure discreet reminders and gentle protection.
- Delete their data from the app.
