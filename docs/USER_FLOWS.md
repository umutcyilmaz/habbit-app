# User Flows

## New User Onboarding Flow

Example user: Mert, 29.

Goal: Let Mert understand Bloom, set a starting profile, and reach Today without over-collecting sensitive data.

1. Welcome
   - Mert sees Bloom's core promise: build awareness before automatic habits.
   - Primary action: Get Started.

2. Safety Note
   - Bloom explains that it is not medical care, diagnosis, or treatment.
   - Bloom encourages users to seek professional or emergency support when appropriate.
   - Primary action: Continue.

3. Privacy / Trust
   - Bloom explains local-first thinking, discreet notifications, and data deletion.
   - Primary action: Continue.
   - Secondary action: Learn More.

4. Goal Selection
   - Mert selects goals such as pause before automatic habits, reduce adult-content loops, reduce rushing, and improve arousal awareness.
   - Primary action: Continue.

5. Adaptive Questions
   - Bloom asks a short set of optional questions about moments, triggers, sensitive windows, and support style.
   - Mert can skip sensitive questions.

6. Starting Profile
   - Bloom summarizes Mert's starting pattern in neutral language.
   - Example: "Evenings may be a sensitive window, especially when boredom is present."

7. Starting Plan
   - Bloom suggests a simple plan: Quick Check-In, Pause Now, Daily Log, and a gentle evening reminder.
   - Mert can edit or accept the plan.

8. Today Dashboard
   - Mert lands on Today, the home base.

## Daily Usage Flow

Goal: Help Mert use Bloom in a calm, lightweight way.

1. Mert opens Bloom.
2. Today shows a small set of timely actions:
   - Quick Check-In
   - Pause Now
   - Add Log
   - Suggested exercise
   - Sensitive window reminder when relevant
3. Mert completes one action.
4. Today updates with a simple reflection prompt or next gentle step.
5. If there is no data yet, Bloom shows an empty state that invites a first check-in without pressure.

## Pause Flow

Goal: Create space before an automatic loop without framing the moment as failure.

1. Entry points:
   - Today Dashboard
   - Protect tab
   - Notification
   - Protected Window Delay
2. Mert taps Pause Now.
3. Bloom asks what is present:
   - Boredom
   - Stress
   - Tiredness
   - Alone time
   - After social media
   - Other
   - Skip
4. Mert starts a 90-Second Pause.
5. Bloom guides a simple grounding practice with no therapy-heavy language.
6. After the pause, Mert chooses:
   - Continue intentionally
   - Do something else
   - Reflect briefly
   - Skip reflection
7. Bloom saves only the needed PauseSession data.

## Log Flow

Goal: Help Mert reflect on a moment without judgment.

1. Entry points:
   - Log tab
   - Today quick action
   - After Pause Check-In
2. Mert chooses a log type:
   - Quick Check-In
   - Content Reflection
   - Arousal Awareness
   - Routine Note
3. Mert selects optional context:
   - Time of day
   - Mood
   - Trigger
   - Adult content present or not
   - Rushing present or not
   - Intention level
4. Mert can add a private note.
5. Bloom saves the log locally.
6. Bloom confirms with neutral copy: "Saved. You can review patterns when you are ready."

## Weekly Review Flow

Goal: Turn logs and pauses into awareness, not scores.

1. Entry points:
   - Progress tab
   - Weekly reminder
   - Today card when a week is ready
2. Bloom summarizes patterns:
   - Common moments
   - Sensitive windows
   - Helpful pauses
   - Exercises tried
   - Contexts connected with rushing
3. Mert chooses what felt true.
4. Bloom suggests a Next Week Focus:
   - Evening pause
   - Less rushed routine
   - Social media transition
   - Mindful arousal practice
5. Mert accepts, edits, or skips.
6. Bloom stores a WeeklyReview and updates the UserPlan.

## Protection Setup Flow

Goal: Offer gentle support around sensitive windows without hard blocking.

1. Entry points:
   - Protect tab
   - Starting Plan
   - Progress insight
2. Bloom explains protection as optional support.
3. Mert chooses a sensitive window:
   - Days
   - Start time
   - End time
   - Label
4. Mert chooses a support style:
   - Gentle
   - Balanced
   - Direct
5. Mert configures actions:
   - Delay prompt
   - 90-Second Pause
   - Discreet reminder
   - Suggested exercise
6. Mert confirms.
7. During a protected window, Bloom can show a Protected Window Delay before an automatic loop continues.
8. Mert can edit, disable, or delete the window at any time.

## Privacy / Data Controls Flow

Goal: Make trust controls easy to find and understand.

1. Entry points:
   - Header settings
   - Account & Settings
   - Privacy Overview
2. Mert reviews:
   - Local-first data approach
   - Notification privacy
   - App lock status
   - Data export availability
   - Data deletion
3. Mert can update:
   - Notification wording level
   - Reminder timing
   - App lock
   - Analytics preference, if analytics exists later
4. Mert can export data when supported.
5. Mert can delete data.
6. Bloom asks for confirmation before deletion.
7. Bloom deletes local data and shows a clear completion state.

## Flow Principles

- Every sensitive question should be optional.
- Every reflection should allow skipping.
- Every protection feature should be editable and reversible.
- Data deletion should never be hidden.
- Progress should summarize patterns, not grade behavior.
- Copy should reinforce control, privacy, and no judgment.
